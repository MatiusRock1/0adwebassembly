0 A.D., running in your browser

The full real-time strategy game by Wildfire Games, compiled to WebAssembly: the original engine, simulation, interface and AI, rendered with WebGPU. No installation.

Play in the browser Source of this port Original 0 A.D. repository

Single-player only: multiplayer (the online lobby and LAN games) does not work in this browser version. Play skirmish matches against the AI.

The first start downloads about 2 GB of game data; later starts reuse the browser's cache.

What this is

  • The original C++ engine (Pyrogenesis) built with Emscripten, with the original game data, simulation, GUI and Petra AI. Nothing is reimplemented in JavaScript.
  • SpiderMonkey 128 runs the game scripts inside WebAssembly; the AI runs on its own thread.
  • A WebGPU renderer in a dedicated worker, with frames paced to a steady 30 FPS.
  • Game archives are streamed in blocks and kept in IndexedDB, so a second visit starts quickly.

Requirements

  • A desktop Chromium browser with WebGPU and WebAssembly JSPI: Chrome or Edge 137 or later.
  • A desktop computer with a capable GPU, mouse and keyboard. Development and the measurements below used Chrome 155 on an NVIDIA RTX 3060 Laptop GPU; other GPUs are untested.
  • In the launcher, the WebGPU (experimental) renderer; the button above selects it. WebGL 2 is available as a fallback.

Performance

Combat test with about 250 units fighting, Chrome on an RTX 3060 Laptop GPU, 1920×1080, 60 Hz display:

30 FPSsteady, locked at the 30 FPS cap
33.4 ms95th percentile frame interval (two refreshes)
1 pauseover 100 ms per minute of combat

Short development measurements, not a certified benchmark; results depend on the browser, GPU and display.
